# Portfólio — Davi Moura

Site pessoal de apresentação e portfólio, desenvolvido em HTML, CSS e JavaScript puro. Reúne informações sobre mim, meus projetos, tecnologias e formas de contato.

🌐 **Acesse:** [davim07.github.io/Site-portfolio](https://davim07.github.io/Site-portfolio/)

## ✨ Funcionalidades

- **Tema claro/escuro** com botão de alternância e preferência salva no navegador
- **Sobre mim**, com apresentação pessoal e objetivos
- **Projetos** em cards com imagem, descrição e link para o repositório no GitHub
- **Skills**, com ícones das tecnologias que utilizo
- **Contatos** com links para GitHub, LinkedIn, e-mail e WhatsApp
- **Formulário de contato** que envia a mensagem diretamente para o meu WhatsApp, já preenchida com nome, e-mail e texto
- **Layout responsivo**, adaptado para celular, tablet e desktop
- Fundo animado com fitas onduladas em SVG e cards com efeito de vidro (*glassmorphism*)

## 🛠️ Tecnologias

- HTML5 semântico
- CSS3 (variáveis, grid, flexbox, `backdrop-filter` e animações)
- JavaScript puro, sem frameworks ou dependências
- GitHub Pages para hospedagem

## 📁 Estrutura

```
├── index.html      # Estrutura e conteúdo da página
├── style.css       # Estilos, temas claro/escuro e animações
├── script.js       # Alternância de tema e envio do formulário via WhatsApp
└── img/            # Avatar e imagens dos projetos
```

## 🚀 Rodando localmente

Por ser um site estático, basta abrir o `index.html` no navegador. Para simular um servidor local:

```bash
python3 -m http.server 8000
```

Depois acesse `http://localhost:8000`.
